BulkPlanting - plant whole fields at once in Valheim
=====================================================

INSTALL
  1. Close Valheim.
  2. Extract this zip anywhere (right-click > Extract All).
  3. Double-click Install.bat.
     If Windows shows "Windows protected your PC", click "More info" > "Run anyway".
  4. Start Valheim from Steam as usual.

The installer finds Valheim through Steam, installs the BepInEx mod loader if you
don't have it yet, and copies BulkPlanting.dll into Valheim\BepInEx\plugins\BulkPlanting.
If you use r2modman or Thunderstore Mod Manager instead, skip the installer and
copy BulkPlanting.dll into your profile's BepInEx\plugins folder.

USE
  Equip the Cultivator, pick a seed, and left-click to plant the whole grid.
    N                        bulk planting on/off
    Left/Right arrows        fewer/more columns
    Down/Up arrows           fewer/more rows
    Left Alt + mouse wheel   shrink/grow the whole grid
    Mouse wheel              rotate the grid
    H                        hex or square pattern

  Settings: Valheim\BepInEx\config\igorr.BulkPlanting.cfg (created after the first launch).

UNINSTALL
  Double-click Uninstall.bat.

More info: https://github.com/neiios/valheim-planting
